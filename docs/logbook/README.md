# Lab logbook

Add one Markdown file per meaningful work session using `YYYY-MM-DD-short-description.md`.

Each entry should contain:

- objective;
- work completed;
- commands or links to an experiment manifest;
- observed facts and results;
- decisions made or still pending;
- next action.

Do not rewrite an old entry to make a later outcome look expected. Add a correction or a new entry instead.
